# 나만의 퀴즈 게임

## 프로젝트 개요
터미널에서 동작하는 4지선다 퀴즈 게임입니다.
Python 클래스로 코드를 구조화하고, JSON 파일로 퀴즈와 점수를 영속화합니다.

## 퀴즈 주제와 선정 이유
- 주제: 파이썬 기초 문법
- 이유: 학습한 내용을 퀴즈로 만들며 스스로 복습하기 위해 선정했습니다.

## 실행 방법
python main.py 명령으로 실행합니다. (Python 3.10 이상, 외부 라이브러리 불필요)

## 기능 목록
1. 퀴즈 풀기 — 랜덤 순서 출제, 채점, 결과 표시
2. 퀴즈 추가 — 문제/선택지 4개/정답 입력 후 저장
3. 퀴즈 목록 — 등록된 퀴즈 확인
4. 점수 확인 — 최고 점수 확인 (자동 갱신)
5. 종료 — 저장 후 안전 종료

## 파일 구조
- main.py : 프로그램 진입점
- quiz.py : Quiz 클래스, 기본 퀴즈 데이터
- quiz_game.py : QuizGame 클래스 (메뉴, 입력 처리, 저장/불러오기)
- state.json : 퀴즈와 최고 점수가 저장되는 데이터 파일

## 데이터 파일 설명 (state.json)
- 경로: 프로젝트 루트
- 역할: 퀴즈 목록과 최고 점수를 UTF-8로 저장
- 스키마:
  - quizzes: 퀴즈 목록 (id, question, choices, answer)
  - best_score: 최고 점수 (기록 없으면 null)
- 파일이 없으면 기본 퀴즈로 시작하고, 손상되면 기본 퀴즈로 복구합니다.
